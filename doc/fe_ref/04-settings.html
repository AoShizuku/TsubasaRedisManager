设计要点
  • 设置项一律用 「标题 + 一行说明 + 右侧控件」 的行式布局，不用卡片分块。说明文字负责解释「这个开关会造成什么后果」，而不是复述标题。
  • 分组顺序按使用频率排：应用（通用 / 外观 / 编辑器）→ 数据（连接与安全 / 数据查看器 / 格式化器）→ 其他（快捷键 / 关于）。
  • 「数据查看器」直接把后端 codec_support_matrix() 的九种编码及其能力（Rust 往返 / 渲染层往返 / 只读）摊开展示，用户能立刻知道哪些格式能改、哪些只能看。
  • 「格式化器」把外部命令的安全约束（禁止 .bat/.cmd、超时、输出上限）写在界面上，而不是等执行失败再报错。
  • 设置改动即时生效并自动保存，底部只保留「恢复本页默认值」和「完成」，不做「应用 / 确定 / 取消」三按钮那一套。
