设计要点
  • 侧栏是唯一的导航区：连接 → DB → namespace → key 全部在同一棵树里，不做二级抽屉。折叠状态下只显示连接，避免冷启动时的信息噪声。
  • 连接右侧的图标徽标对应后端 ConnectionSummary 的 cluster / readonly / sshEnabled / tlsEnabled / sentinelEnabled，颜色圆点对应 color 字段。
  • 标题栏中央的 omnibar 是全局入口（Key 搜索 + 命令面板），和 Key 内容搜索严格分开，后者在编辑器工具条上。
  • 空态不用卡片：一个品牌标记、两个动作、一段最近记录、一行快捷键提示。Redis 红只出现在品牌标记和 只读 徽标上。
  • 底部状态栏在未连接时也保留，位置固定，避免连接后布局跳动。
